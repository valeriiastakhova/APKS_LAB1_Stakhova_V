# Hello World AI Agent

## Дані роботи

- **ПІБ:** Стахова Валерія Юріївна
- **Група:** КІ-406
- **Варіант:** 6
- **Мова:** TypeScript
- **Система складання та запуску:** npm scripts
- **Тестування:** Vitest

## Опис проєкту

Проєкт демонструє мінімальний Hello World і керування його життєвим циклом
через AI-агента Build Engineer. Агент аналізує структуру репозиторію, готує
або перевіряє TypeScript-збірку, запускає тести Vitest і повідомляє про
результат. Така демонстрація показує, як агент може безпечно автоматизувати
типові операції складання, не змінюючи файли поза межами поставленої задачі.

Очікуваний результат виконання програми:

```text
Hello, World!
```

## Передумови

- Node.js 20 або новіший;
- npm, що постачається разом із Node.js;
- клонований репозиторій і права на читання та запис файлів проєкту.

## Встановлення залежностей

```bash
npm install
```

## Запуск Hello World

Команди залежать від скриптів у `package.json`. Рекомендований набір для
проєкту:

```bash
npm run build
npm start
```

Для локального режиму розробки:

```bash
npm run dev
```

## Запуск тестів

```bash
npm test
```

Одноразовий запуск Vitest у CI:

```bash
npm run test:run
```

## Як запустити AI-агента

1. Відкрийте репозиторій у VS Code із підтримкою Copilot/AI-агентів.
2. Відкрийте маніфест [Build Engineer](agents/build-engineer.agent.md).
3. Передайте агенту чітку задачу, наприклад:  
   `Перевір TypeScript-збірку, запусти Vitest і повідом результат.`
4. Агент працює за архітектурою з [docs/architecture.md](docs/architecture.md):
   спочатку аналізує контекст, потім виконує дозволені npm-команди, перевіряє
   результат і формує звіт.
5. Перегляньте запропоновані зміни та результати команд перед прийняттям.

Агент не має автоматично видаляти файли, публікувати секрети або виконувати
непогоджені руйнівні операції.
