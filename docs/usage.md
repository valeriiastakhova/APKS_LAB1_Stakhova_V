# Використання проєкту

## Запуск AI-агента

Щоб згенерувати проєкт за допомогою AI-агента:

1. Відкрийте **Copilot Chat** у VS Code.
2. Прикріпіть до повідомлення файли `#build-engineer.agent.md` та
   `#init.prompt.md`.
3. Відправте запит на виконання оркестратора, наприклад:

   ```text
   Виконай оркестратор init для створення та перевірки TypeScript-проєкту.
   ```

Агент послідовно виконає команди ініціалізації, створить необхідні файли та
повідомить про результати перевірки.

## Локальна перевірка

Для перевірки згенерованого коду відкрийте термінал у корені проєкту та
виконайте:

```bash
npm install
npm run build
npm run test
```
